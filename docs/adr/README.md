# Decisões (ADR)

Uma decisão por arquivo. Só entra aqui o que passa nos **três** critérios ao mesmo tempo:

1. difícil de reverter;
2. surpreendente para quem chega sem contexto;
3. resultado de um trade-off real — havia outra opção defensável.

**O que NÃO entra:** política global que vale em todos os projetos do Diego — `main` protegida, PR
sempre, sem branch `develop`. Isso vive no `~/AGENTS.md` e vale aqui por herança. Copiar para cá
cria cópias que divergem em um mês.

Decisão de política **com particularidade local** entra normalmente — por exemplo, o nome exato de
um check que não pode ser renomeado.
